# Roadmap

## Near Term

- Add `--profile` for library, app, docs, dataset, and template repositories
- Add SARIF output
- Add pre-commit documentation
- Add more package metadata checks
- Publish to PyPI

## Mid Term

- Add GitHub Action wrapper
- Add machine-readable rule documentation
- Add optional GitHub API enrichment for topics, description, and visibility
- Add `--fix-stubs` mode to create missing template files

## Long Term

- Maintain an open-source launch benchmark
- Add score history reports
- Add organization-wide repo audit mode
- Provide integration examples for Codex, Claude Code, Cursor, and Copilot workflows

## Non-Goals

- No default network calls
- No model-based scoring by default
- No claims that a high score guarantees stars or adoption
